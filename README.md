# FakeDeS_IberLEF_2021
Creación de un sistema que permita detectar desinformación para contribuir al filtrado de contenido potencialmente engañoso, conforme al task FakeDeS: Fake News Detection in Spanish Shared Task at IberLEF 2021, organizada en colaboración con MexLef. Proyecto final de la asignatura Minería de Datos, impartida en la LCD, IIMAS, UNAM.
